# NSE Stock Intelligence

A standalone sector-wise NSE stock analysis dashboard. Open `index.html` directly in a browser.

## Included
- Sector explorer
- Stock search
- Fundamental/growth/valuation/risk scoring
- Sortable stock table
- Deep stock analysis modal
- Responsive mobile layout
- Data/analysis separation ready for a live data provider

## Important
The included stock metrics are illustrative demo values, not a live market feed. Connect a permitted/licensed NSE or market-data API and refresh metrics before using the app for investment decisions.

## GitHub
Create an empty GitHub repository, upload `index.html` and `README.md`, then enable GitHub Pages from Settings → Pages → Deploy from branch.
